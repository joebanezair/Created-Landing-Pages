## Current features

- Responsive virtual staffing landing page
- Services for customer support, appointment setters, admin/VA, and technical support
- Staffing process section
- Pricing/service-model section
- FAQ section
- CTA modal and lead form UI
- Placeholder areas for verified case studies and client reviews
- Vercel-ready static deployment configuration

## Development

The first version is intentionally lightweight HTML, CSS, and JavaScript so it is easy to maintain and extend.

Open `index.html` directly for basic local testing, or run it through any static development server.

## Trust policy

Do not publish invented ratings, testimonials, client logos, placement numbers, or case-study results. Replace placeholders only with claims and reviews that can be verified.
